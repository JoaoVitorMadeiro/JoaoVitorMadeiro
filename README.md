### 🚀 Sobre Mim: Onde a Lógica Encontra a Arquitetura

Não escrevo apenas código; **eu projeto sistemas**. Minha atuação profissional se posiciona na interseção entre a engenharia de software robusta e o design criativo de regras complexas.

Com uma base sólida em **Java e Spring Boot**, foco na construção de arquiteturas escaláveis, microsserviços resilientes e consistência de dados. Paralelamente, aplico minha experiência em **Lógica de Jogos e RPG** para resolver problemas complexos de balanceamento e modelagem de regras de negócio, trazendo uma visão única de "Game Design" para a engenharia de software.

Atualmente, estou expandindo minha stack para o ecossistema **Node.js/Vue.js** e aprofundando pesquisas em **Interação Humano-Computador (IHC)** e Acessibilidade.
